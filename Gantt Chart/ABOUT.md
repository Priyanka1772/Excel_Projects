## Showroom Project – Gantt Chart & Project Planning (Forage)

## Project Overview
* This project focuses on creating a realistic project plan for a high-end showroom using a Gantt Chart.
* Built as part of a professional simulation on Forage, the project applies project management and capital planning concepts in a commercial real estate context.
* The objective was to sequence project activities logically while accounting for dependencies, risks, and real-world constraints.

## Project Context
* Client: Global manufacturer of high-end kitchen appliances (simulated)
* Project: Experiential downtown showroom with live test kitchens
* Role: Project Manager
* Tool Used: Microsoft Excel

## Key Features
* End-to-End Project Timeline: Covers phases from project kickoff through showroom launch.
* Dependency Mapping: Identifies logical sequencing across design, approvals, procurement, construction, and commissioning.
* Risk-Aware Scheduling: Accounts for regulatory approvals, construction timelines, and testing requirements.
* Gantt Chart Visualization: Uses conditional formatting in Excel to clearly represent task durations and overlaps.

## Concepts Applied
* Gantt Charts & Project Scheduling
* Critical Path Awareness
* Dependency & Risk Management
* Capital Planning Fundamentals
* Real Estate Fit-Out Project Lifecycle

## Key Skills Demonstrated
* Project Planning & Scheduling
* Analytical Thinking
* Risk Identification & Mitigation
* Stakeholder-Oriented Planning
* Professional Documentation
